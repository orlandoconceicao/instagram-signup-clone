# Clone da Página de Login do Instagram

Projeto de estudo que recria a interface de login do Instagram com HTML e CSS, com foco em estrutura semântica, Flexbox e adaptação para telas menores.

## Funcionalidades

- formulário visual de login;
- links auxiliares de acesso e recuperação;
- botões de download do aplicativo;
- layout responsivo com ocultação do banner em telas pequenas.

## Tecnologias

HTML5, CSS3, Flexbox e media queries.

## Execução

Abra o arquivo `index.html` no navegador.
